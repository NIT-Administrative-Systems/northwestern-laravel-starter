Environment Variables

The starter reads these variables from .env through the files in config/. The Default column is what the config uses when the variable is not set. .env.example sets some of them to different values for local development.

An empty value is not an unset value

FOO= sets FOO to an empty string, and the empty string overrides the config default. Delete or comment out the line to get the default. Laravel converts the values true, false, null and empty (with or without parentheses) to true, false, null and ''.

Laravel’s own configuration files read many more variables than this page lists: the long tail in config/database.php, config/cache.php, config/session.php, config/logging.php, config/mail.php, config/queue.php and config/broadcasting.php. This page lists only those in .env.example or added by the starter. See Laravel’s configuration documentation and the config file itself for the rest.

Testing

Section titled “Testing”

phpunit.xml sets its own values for the PHP and browser tests, including APP_ENV=testing and DB_CONNECTION=phpunit. Browser tests run the application inside the test process, so they use the same values. See Testing.
