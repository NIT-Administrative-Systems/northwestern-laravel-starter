## System Requirements

- **PHP**: `^8.4`
- **Node.js**: `v25.x`
- **pnpm**: `^10.0`
- **Database**: PostgreSQL `16+`, MySQL `8.0+`, or SQLite `3.35+`

### PHP Extensions

The following PHP extensions are required to satisfy application dependencies:

```text
ext-ctype       ext-curl        ext-dom         ext-fileinfo
ext-filter      ext-hash        ext-iconv       ext-intl
ext-json        ext-libxml      ext-mbstring    ext-openssl
ext-pcre        ext-pdo         ext-phar        ext-reflection
ext-session     ext-simplexml   ext-sodium      ext-tokenizer
ext-xml         ext-xmlreader   ext-xmlwriter   ext-zip
```

### Database Requirements

<Aside type="note" title="Supported Databases">
The following database engines are officially supported and tested in CI:

- **PostgreSQL** `16+`
- **MySQL** `8.0+`
- **SQLite** `3.35+`

PostgreSQL is the default and recommended driver for production deployments. MySQL is fully supported as an alternative. SQLite is suitable for local development, testing, and lightweight deployments.

Set the `DB_CONNECTION` environment variable in your `.env` file to switch drivers (`pgsql`, `mysql`, or `sqlite`).
</Aside>

## Local Development Setup

<CardGrid>
  <Card title="Laravel Herd" icon="rocket">
    **Recommended**

    [Laravel Herd](https://herd.laravel.com/) provides an all-in-one development environment for macOS and Windows:
    - PHP 8.4+ with extension management
    - Nginx web server
    - PostgreSQL, MySQL, Redis, and MinIO services
    - Automatic site provisioning
  </Card>

  <Card title="Laravel Valet" icon="seti:config">
    **Alternative**

    [Laravel Valet](https://laravel.com/docs/valet) is a lightweight macOS environment requiring manual installation of PHP, your chosen database (PostgreSQL, MySQL, or SQLite), and other dependencies.

    Suitable as an alternative if you cannot use Laravel Herd.
  </Card>
</CardGrid>

## Northwestern-Specific Requirements

<Aside type="caution" title="API Access Required">
Access to Northwestern integrations requires approval and credentials through the [API Service Registry](https://apiserviceregistry.northwestern.edu).
</Aside>

To make the most of this project, you'll need access to the following integrations:

<CardGrid stagger>
  <Card title="WebSSO / Entra ID" icon="approve-check">
    SSO configuration for Northwestern authentication. Depending on your authentication strategy, you'll need either **Entra ID** credentials (via Azure application registration) or an **Online Passport** API key (via the API Service Registry).

    **Required** for user authentication via NetID.
  </Card>

  <Card title="Directory Search" icon="magnifier">
    Service responsible for user lookups, demographic sync, and organizational data.

    **Required** for Northwestern user provisioning.
  </Card>

  <Card title="EventHub" icon="rocket">
    Webhook configuration and HMAC shared secret for event subscriptions.

    **Optional** - Only needed if consuming or publishing events.
  </Card>

  <Card title="NetID Updates Event Message" icon="information">
    Subscription to the `etidentity.ldap.netid.term` topic for receiving NetID lifecycle events.

    **Optional** - Enables automatic role removal when users leave Northwestern. Requires EventHub access.
  </Card>
</CardGrid>
