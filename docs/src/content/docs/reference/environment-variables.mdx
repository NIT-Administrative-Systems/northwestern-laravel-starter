The starter reads these variables from `.env` through the files in `config/`. The **Default** column is what the config uses when the variable is not set. `.env.example` sets some of them to different values for local development.

<Aside type="caution" title="An empty value is not an unset value">
    `FOO=` sets `FOO` to an empty string, and the empty string overrides the
    config default. Delete or comment out the line to get the default. Laravel
    converts the values `true`, `false`, `null` and `empty` (with or without
    parentheses) to `true`, `false`, `null` and `''`.
</Aside>

Laravel's own configuration files read many more variables than this page lists: the long tail in `config/database.php`, `config/cache.php`, `config/session.php`, `config/logging.php`, `config/mail.php`, `config/queue.php` and `config/broadcasting.php`. This page lists only those in `.env.example` or added by the starter. See [Laravel's configuration documentation](https://laravel.com/docs/configuration) and the config file itself for the rest.

## Application

| Variable                   | Default                    | Description                                                                                                                                              |
| -------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP_NAME`                 | `Laravel`                  | Application name, shown in the header, emails and the browser title                                                                                      |
| `APP_ENV`                  | `production`               | Environment name. The starter recognizes `local`, `testing`, `ci`, `develop`, `qa`, `staging` and `production`                                           |
| `APP_KEY`                  | `null`                     | Encryption key. Generate it with `php artisan key:generate`                                                                                              |
| `APP_DEBUG`                | `false`                    | Show detailed error pages. Never `true` in production                                                                                                    |
| `APP_URL`                  | `http://localhost`         | Base URL of this environment                                                                                                                             |
| `PRODUCTION_URL`           | `https://northwestern.edu` | URL of the production environment, linked from the [lockdown page](/getting-started/initial-customization/#5-environment-lockdown) in other environments |
| `APP_LOCALE`               | `en`                       | Default locale                                                                                                                                           |
| `APP_FALLBACK_LOCALE`      | `en`                       | Locale used when a translation is missing                                                                                                                |
| `APP_FAKER_LOCALE`         | `en_US`                    | Locale for factory data                                                                                                                                  |
| `APP_MAINTENANCE_DRIVER`   | `file`                     | Where maintenance mode is stored (`file` or `cache`)                                                                                                     |
| `APP_MAINTENANCE_STORE`    | `database`                 | Cache store for maintenance mode when the driver is `cache`                                                                                              |
| `BCRYPT_ROUNDS`            | `12`                       | Password hashing cost                                                                                                                                    |
| `DEFAULT_USER_TIMEZONE`    | `America/Chicago`          | Timezone given to users that Directory Search creates, and the `users.timezone` column's default, set when the migration runs. Changing it later doesn't change existing users or the column |
| `AUDITING_ENABLED`         | `true`                     | Record model changes. See [Audit Logging](/features/audit-logging/)                                                                                      |
| `LOG_CHANNEL`              | `stack`                    | Default log channel                                                                                                                                      |
| `LOG_STACK`                | `single`                   | Comma-separated channels the `stack` channel writes to                                                                                                   |
| `LOG_DEPRECATIONS_CHANNEL` | `null`                     | Channel for PHP and library deprecation warnings                                                                                                         |
| `LOG_LEVEL`                | `debug`                    | Minimum level written to the logs                                                                                                                        |

| `TELESCOPE_ENABLED` | `true`                       | Record requests, queries, jobs and more in Telescope                                                                                                    |
| `DEBUGBAR_ENABLED`  | `null` (follows `APP_DEBUG`) | Show Laravel Debugbar                                                                                                                                   |
| `RAY_ENABLED`       | `true` outside production    | Send `ray()` output to the Ray app                                                                                                                      |
| `PG_BIN_DIRECTORY`  | `null` (auto-detected)       | Directory containing `pg_dump` and `psql`, for the `db:snapshot:*` commands. See [Database Snapshots](/features/database-snapshots/)                   |

`config/telescope.php` and `config/debugbar.php` read many more `TELESCOPE_*` and `DEBUGBAR_*` variables. Their defaults are in those files.

## Testing

| Variable | Default | Description                                                                     |
| -------- | ------- | ------------------------------------------------------------------------------- |
| `CI`     | unset   | Set by CI providers. When set, `starter:check` skips the upstream version check |

`phpunit.xml` sets its own values for the PHP and browser tests, including `APP_ENV=testing` and `DB_CONNECTION=phpunit`. Browser tests run the application inside the test process, so they use the same values. See [Testing](/guides/testing/).
